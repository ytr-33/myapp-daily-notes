# バックエンド開発環境

## 開発プロファイルの有効化

開発環境（ローカル実行時）では、H2コンソールや詳細ログ出力を有効にするため、`dev` プロファイルを使用してください。これにより、`application-dev.properties` の設定が読み込まれます。

### 起動方法

#### 1. コマンドライン（Maven）
ターミナルから実行する場合：
```bash
./mvnw spring-boot:run -Dspring-boot.run.profiles=dev
```

#### 2. VS Code (Spring Boot Dashboard)
`.vscode/launch.json` の設定が必要です。
Spring Boot拡張機能を使用している場合、プロファイルを指定してデバッグ実行できます。

#### 3. IntelliJ IDEA / Eclipse
実行構成 (Run/Debug Configurations) の設定で以下を指定します：
- **Active profiles**: `dev`
- または **VM options**: `-Dspring.profiles.active=dev`

### 確認方法
起動ログに以下のような出力があれば、`dev` プロファイルが有効になっています。
```
The following 1 profile is active: "dev"
```
