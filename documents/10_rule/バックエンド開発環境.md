# バックエンド開発環境

## 開発プロファイルの有効化

開発環境（ローカル実行時）では、H2コンソールや詳細ログ出力を有効にするため、`dev` プロファイルを使用してください。これにより、`application-dev.properties` の設定が読み込まれます。

### 起動方法

#### 1. コマンドライン（Maven）
ターミナルから実行する場合：
```bash
./mvnw spring-boot:run -Dspring-boot.run.profiles=dev
```

#### 2. VS Code (Spring Boot Dashboard)
`.vscode/launch.json` の設定が必要です。
Spring Boot拡張機能を使用している場合、プロファイルを指定してデバッグ実行できます。

#### 3. IntelliJ IDEA / Eclipse
実行構成 (Run/Debug Configurations) の設定で以下を指定します：
- **Active profiles**: `dev`
- または **VM options**: `-Dspring.profiles.active=dev`

### 確認方法
起動ログに以下のような出力があれば、`dev` プロファイルが有効になっています。
```
The following 1 profile is active: "dev"
```

## データベースのリセット

開発中にデータベースのデータを初期状態に戻したい場合は、プロジェクトルートにある `reset_db.sh` を実行してください。このスクリプトは、既存のデータを全て削除し、`init.sql` の初期データを再投入します。

```bash
# プロジェクトルートで実行
./reset_db.sh
```

> **Note**
> このスクリプトを実行するには `psql` コマンドが必要です。Dev Container のバックエンド環境には予めインストールされています。

## DBテーブル確認コマンド

### 1. backend dev container 内から確認する場合

```bash
# テーブル一覧
psql -h postgres -U postgres -d myapp_db -c "\dt"

# usersテーブルの中身
psql -h postgres -U postgres -d myapp_db -c "SELECT * FROM users;"
```

### 2. ローカルPCから確認する場合

```bash
# テーブル一覧
docker exec -it myapp-postgres psql -U postgres -d myapp_db -c "\dt"

# usersテーブルの中身
docker exec -it myapp-postgres psql -U postgres -d myapp_db -c "SELECT * FROM users;"
```
