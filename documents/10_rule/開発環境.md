## Docker Compose ネットワーク構成

カスタムブリッジネットワーク `myapp-network` により、コンテナ間通信を実現：

```
frontend (3000) ──┐
                  ├─ myapp-network ─── postgres (5432)
backend (8080) ───┘
```

### 通信パターン

| 呼び出し元 | 宛先 | アドレス | 経路 |
|----------|------|---------|------|
| ブラウザ | Backend API | `http://localhost:8080` | ポートフォワーディング経由 |
| Backend | PostgreSQL | `postgres:5432` | Docker内部ネットワーク (サービス名解決) |
| Frontend SSR | Backend API | `http://backend:8080` | Docker内部ネットワーク |

**注意**: 
- ブラウザからのAPI呼び出しは、ホストマシンの`localhost`経由でアクセス
- コンテナ間通信は、サービス名（`postgres`, `backend`）を使用してDNS自動解決
