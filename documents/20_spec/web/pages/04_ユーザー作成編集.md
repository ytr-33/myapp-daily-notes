# ユーザー作成/編集

## 目的
- ユーザーの新規作成と更新を行う。

## 入力項目
- 名前（必須）
- メール（必須/メール形式）
- 電話（任意）
- 年齢（任意/0以上）

## API 連携
- 作成: `POST /api/users`
- 更新: `PUT /api/users/{id}`
- 編集画面初期表示: `GET /api/users/{id}`

## UI 仕様
- 共通フォームで作成/編集を切替
- 送信中はボタンを無効化

## エラーハンドリング
- 400: 入力エラーを各項目に表示
- 409: メール重複エラーを表示
- 500: 共通エラーバナー
