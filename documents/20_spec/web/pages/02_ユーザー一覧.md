# ユーザー一覧

## 目的
- ユーザーの一覧表示、検索、詳細への導線を提供する。

## 表示内容
- 一覧テーブル
  - 名前 / メール / 電話 / 年齢
- 操作ボタン
  - 詳細 / 編集 / 削除
- 検索
  - メールアドレスで検索

## API 連携
- `GET /api/users`
  - 一覧取得
- `GET /api/users/search/email?email=...`
  - メール検索
- `DELETE /api/users/{id}`
  - 削除（一覧から実行）

## UI 仕様
- テーブル + 行アクション
- 検索フォームは一覧上部

## エラーハンドリング
- 取得失敗時はエラーバナー表示
- 削除失敗時はダイアログ/トーストで通知
