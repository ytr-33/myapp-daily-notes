# Daily Notes プロジェクト — 進め方（整理版）

## 概要
日々のタスクを管理するためのシンプルなアプリケーション。最初はガントチャート（課題、工数、期日）に注力し、将来的にSNS連携やAI支援などの機能を追加する予定。

## 目的
- devcontainer と `docker compose` を使った開発環境構築の学習
- フロント（Next.js）／バックエンド（Java）／Postgres を組み合わせたフルスタック開発の理解

## 技術スタック
- バックエンド: Java（Spring Boot 推奨）
- フロント: Next.js（TypeScript）
- DB: PostgreSQL

## 開発方針
- VS Code の `devcontainer` 内で開発・テストを行う
- 開発環境は `docker compose` で再現可能にする
- 小さく始めて逐次拡張（Hello World → API → DB → UI）

## 目標フェーズ（高レベル）
1. 環境構築（devcontainer, docker-compose, Java, Node, Postgres）
2. 動作確認（backend/ frontend の Hello World、DB接続）
3. アプリ開発（ガントチャート等）
4. 単体テスト・結合テスト
5. CI 整備・リリース準備

## 手順（上から順に、実行可能な詳細）

### 1. devcontainer 設定作成
1. ワークスペース直下に `.devcontainer/` を作成する。
2. `devcontainer.json` を用意し、使用する `Dockerfile`、フォワードポート、推奨拡張を定義する。
3. `Dockerfile` に OpenJDK、Maven/Gradle、Node.js、pnpm（または yarn）等をインストールする。
4. VS Code で「Reopen in Container」を実行し、コンテナ内で `java -version` / `node -v` 等が確認できれば完了。

devcontainer の雛形（要調整）:
```json
{
  "name": "daily-notes-dev",
  "build": { "dockerfile": "Dockerfile" },
  "workspaceFolder": "/workspace",
  "forwardPorts": [3000, 8080],
  "extensions": ["ms-azuretools.vscode-docker","redhat.java","vscjava.vscode-java-pack","esbenp.prettier-vscode","dbaeumer.vscode-eslint"],
  "settings": { "terminal.integrated.shell.linux": "/bin/bash" }
}
```

### 2. docker-compose 設定追加
1. プロジェクトルートに `docker-compose.yml` と `.env.example` を作成する（機密は `.env` に入れる）。
2. サービス: `frontend`（Next.js）、`backend`（Spring Boot）、`db`（Postgres）を定義する。
3. DB 永続化用にボリュームを設定し、初期スキーマは `db/init` に置く。

簡易 `docker-compose.yml` の例（要プロジェクト向け調整）:
```yaml
version: '3.8'
services:
  frontend:
    build: ./frontend
    ports: ['3000:3000']
    depends_on: ['backend']
    environment: ['NEXT_PUBLIC_API_URL=http://backend:8080']

  backend:
    build: ./backend
    ports: ['8080:8080']
    environment: ['SPRING_DATASOURCE_URL=jdbc:postgresql://db:5432/dailynotes','SPRING_DATASOURCE_USERNAME=postgres','SPRING_DATASOURCE_PASSWORD=postgres']
    depends_on: ['db']

  db:
    image: postgres:15
    environment: ['POSTGRES_DB=dailynotes','POSTGRES_USER=postgres','POSTGRES_PASSWORD=postgres']
    volumes: ['db_data:/var/lib/postgresql/data']

volumes: { db_data: {} }
```

### 3. Java バックエンド骨組み
1. `backend/` を作成し、Spring Initializr で最小構成（web, data-jpa, postgresql）を生成する。
2. `HealthController` を作り `/api/health` を返す簡易エンドポイントを実装する。
3. `application.yml` では環境変数を参照する（Compose と合わせる）。
4. Dockerfile（マルチステージ）を用意し、`mvnw package` → 実行イメージを作る。

最小コマンド例:
```bash
mkdir backend && cd backend
curl https://start.spring.io/starter.tgz -d dependencies=web,data-jpa,postgresql -d packageName=jp.example.dailynotes | tar -xz
./mvnw -DskipTests package
```

### 4. Next.js フロント骨組み
1. `frontend/` を作成し、Next.js（TypeScript）で初期化する。
2. `pages/index.tsx` に Hello World と `fetch` で `NEXT_PUBLIC_API_URL` の `/api/health` を呼ぶコードを置く。
3. 開発用の Dockerfile を用意し、`pnpm dev` で起動できるようにする。

例コマンド:
```bash
mkdir frontend && cd frontend
pnpm create next-app@latest . --typescript
pnpm dev
```

### 5. Postgres 初期化
1. `db/init/V1__init.sql` にスキーマ定義やサンプルデータを置く。
2. `docker-compose.yml` の `db` で `docker-entrypoint-initdb.d` を使うと初回起動時に実行される。

### 6. VS Code タスク & デバッグ設定
1. `.vscode/tasks.json` にビルド・起動・テスト用タスクを追加する。
2. `.vscode/launch.json` で Java のリモートデバッグや複合起動を設定する。

### 7. テスト（単体・結合）
1. Java: `JUnit` / `Spring Boot Test` でコントローラ・リポジトリのスモークテストを追加。
2. Next.js: `Jest` + `React Testing Library` を導入してコンポーネントの単体テストを追加。
3. CI で自動実行されるように設定する。
